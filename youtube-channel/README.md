# YouTube Channel Project

Проект по созданию и развитию YouTube-канала с целью выйти на устойчивую монетизацию и доход.

## Основные правила
- Вся существенная работа по проекту фиксируется в этом репозитории.
- Не терять решения, тесты, результаты, идеи и финансовые данные.
- Перед важными решениями сверяться с журналами.
- Новые факты и изменения добавлять в соответствующий журнал.
- Не удалять историю без явной необходимости; при изменении решения фиксировать, что изменилось и почему.

## Главные документы
- MASTER_HANDOFF.md — полный переносимый контекст проекта.
- MEMORY_RULES.md — правила сохранения и использования контекста.
- PROJECT_JOURNAL.md — хронология проекта.
- CONTENT_JOURNAL.md — идеи и контент.
- VIDEO_LOG.md — опубликованные/планируемые видео и результаты.
- FINANCE_JOURNAL.md — расходы, доходы и монетизация.
- EXPERIMENTS_JOURNAL.md — эксперименты и их результаты.
- RESEARCH_JOURNAL.md — исследования рынка, ниши и конкурентов.
- TASKS.md — текущие задачи и следующие шаги.
